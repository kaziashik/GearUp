## 🚀 Deployment Steps

### Step 1: Build & Test Locally

```powershell
# Build the project
npm run build

# Test the built version
npm start

# Visit: http://localhost:5000
```

You should see: `{"success":true,"message":"GearUp API is running 🏋️","version":"1.0.0"}`

---

### Step 2: Deploy to Vercel (Preview)

```powershell
# Login to Vercel
vercel login

# Deploy preview
vercel
```

**Answer the prompts:**
- Set up and deploy? → `Y`
- Which scope? → Choose your account
- Link to existing project? → `N`
- Project name? → `gearup-backend`
- Directory? → Press `Enter` (use `./`)
- Override settings? → `N`

Vercel will:
1. Automatically run `npm run build` → Creates `dist/server.js`
2. Deploy the bundled server
3. Give you a preview URL: `https://gearup-backend-xxxxx.vercel.app`

**🔍 Test the preview URL:**
```
https://gearup-backend-xxxxx.vercel.app/health
```

---

### Step 3: Set Environment Variables

**Option A: Via Vercel Dashboard (Recommended)**

1. Go to your project on https://vercel.com
2. Click **Settings** → **Environment Variables**
3. Add each variable for **Production**:

```env
NODE_ENV=production
DATABASE_URL=your-postgres-connection-string-here
JWT_ACCESS_SECRET=your-jwt-access-secret-here
JWT_REFRESH_SECRET=your-jwt-refresh-secret-here
JWT_ACCESS_EXPIRES_IN=15m
JWT_REFRESH_EXPIRES_IN=7d
STRIPE_SECRET_KEY=your_stripe_secret_key_here
STRIPE_WEBHOOK_SECRET=your_stripe_webhook_secret_here
GOOGLE_CLIENT_ID=your-google-client-id.apps.googleusercontent.com
```

**⚠️ These need to be updated after frontend deployment:**
```env
STRIPE_SUCCESS_URL=https://YOUR-FRONTEND.vercel.app/payment/success
STRIPE_CANCEL_URL=https://YOUR-FRONTEND.vercel.app/payment/cancel
CLIENT_URL=https://YOUR-FRONTEND.vercel.app
```

**Option B: Via CLI**

```powershell
vercel env add DATABASE_URL production
# Paste your DATABASE_URL when prompted

# Repeat for each variable...
```

---

### Step 4: Deploy to Production

```powershell
vercel --prod
```

Your backend is now live! 🎉

**Production URL:** `https://gearup-backend.vercel.app` (or your custom domain)

## 📝 Build Details

### What `npm run build` does:

1. Runs `tsup` (see `tsup.config.ts`)
2. Bundles `src/server.ts` and all dependencies
3. Outputs:
   - `dist/server.js` (5.13 MB) ← Used by Vercel
   - `dist/server.js.map` (sourcemap)

### Why tsup is better:

- ✅ Bundles all code into a single file
- ✅ Handles Prisma Client properly
- ✅ Works with CommonJS dependencies (like Express)
- ✅ Fast builds (~363ms)
- ✅ Better for serverless (smaller, faster cold starts)

## 🐛 Troubleshooting

### Build fails locally
```powershell
# Clean and rebuild
rm -rf dist node_modules
npm install
npm run build
```

### Prisma Client not found
```powershell
# Regenerate Prisma Client
npm run db:generate
npm run build
```

### Environment variables not working
- Make sure you set them in Vercel dashboard under "Production"
- Redeploy after adding variables: `vercel --prod`

### Database connection errors
- Verify DATABASE_URL is correct
- Check if your Prisma Postgres allows connections from Vercel
- Make sure `sslmode=require` is in the connection string
