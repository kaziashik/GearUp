# GearUp

Sports & outdoor gear rental platform.

## Project structure

```text
GearUp/
├── Backand/     # Express + Prisma API
└── Frontend/    # Next.js app
```

## Quick start

### Backend

```bash
cd Backand
npm install
npm run dev
```

Runs on `http://localhost:5000`

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

Runs on `http://localhost:3000`
