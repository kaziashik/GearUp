## 🚀 Getting Started

### 1. Backend Setup
```bash
cd Backand

# Install dependencies
npm install

# Setup database
npx prisma generate
npx prisma db push --accept-data-loss
npm run db:seed

# Start server
npm run dev
# Backend: http://localhost:5000
```

### 2. Frontend Setup
```bash
cd Frontend

# Install dependencies
npm install

# Start dev server
npm run dev
# Frontend: http://localhost:3000
```

### 3. Test Login
Visit http://localhost:3000/login and use demo buttons:
- **Customer**: customer@gearup.com / Customer@123
- **Provider**: provider@gearup.com / Provider@123
- **Admin**: admin@gearup.com / Admin@123

## 🐛 Known Issues & Fixes

### Database Connection
If login fails, run:
```bash
cd Backand
npx prisma db push --accept-data-loss
npm run db:seed
```

### Google OAuth
Ensure `NEXT_PUBLIC_GOOGLE_CLIENT_ID` matches in both:
- `Frontend/.env.local`
- `Backand/.env`
